# 마태복음 5장 암송 웹앱 — 프로젝트 스펙

중·고등부용 마태복음 5장 암송 자료의 모바일 웹(정적 사이트) 버전.
로그인/서버/DB 없이 **프론트엔드만으로 완결**되는 것이 목표.

## 이미 준비된 것 (이 폴더)

- `data/verses.json` — 절 번호(1~48) → 본문 텍스트
- `data/weeks.json` — 8주차 메타데이터 (구간, 제목, 암송 팁)
- `data/verse-icon-map.json` — 절 번호 → 아이콘 이름 매핑
- `data/week-accent-color.json` — 주차별 포인트 컬러 (gold/teal/coral 순환)
- `data/design-tokens.json` — 색상 팔레트, 폰트
- `assets/icons/*.svg` — 절 상징 아이콘 26종 × 3색상 (원형 배지 포함, 그대로 `<img>` 또는 인라인 SVG로 사용 가능)
- `assets/covers/*.svg` — 주차별 표지 삽화 8장 + 타이틀/클로징 삽화 (벡터라 모바일에서 확대해도 안 깨짐)

## 추천 기술 스택

- **Vite + React + TypeScript + Tailwind CSS** — 정적 SPA, 빌드 결과물만 배포하면 되므로 서버 불필요
- 배포: Vercel / Netlify / GitHub Pages 아무 곳이나 무료로 가능 (빌드 커맨드만 연결하면 끝)
- 상태 관리 라이브러리 불필요 — 페이지 수가 적고 서버 통신이 없으므로 React 기본 상태(useState)로 충분
- 라우팅: `react-router-dom` (또는 Next.js를 쓰고 싶다면 `app router` + `output: 'export'`로 정적 export)

> 굳이 Next.js가 아니어도 됩니다. 백엔드가 없으므로 Vite 쪽이 더 가볍고 빠르게 시작할 수 있어요.

## 화면 구성 (MVP 범위)

### 1. 홈 (`/`)
- 헤더: "마태복음 5장 전체 암송 챌린지"
- `weeks.json`을 순회하며 8개의 주차 카드 렌더링 (아이콘 + 제목 + 절 범위 + 팁 한 줄)
- 카드를 탭하면 `/week/:n` 로 이동

### 2. 주차 상세 (`/week/:n`)
- 상단: 해당 주차의 `assets/covers/cover-weekN.svg`를 배경 또는 히어로 이미지로 표시
- 본문 섹션: `verses.json`에서 `weeks[n].from ~ to` 구간의 절을 순서대로 렌더링
  - 절마다 `verse-icon-map.json`으로 아이콘 결정, 같은 아이콘이 연속되면 그룹으로 묶어 아이콘 1개 + 절 여러 개 표시 (기존 PPTX와 동일한 로직)
- 하단 CTA 버튼: "셀프테스트 시작" → 같은 페이지 내 테스트 모드로 전환 (또는 `/week/:n/test` 라우트로 분리해도 무방)

### 3. 셀프테스트 (`/week/:n/test` 또는 토글 모드)
- 절마다 **첫 어절만 보여주고** 나머지를 가릴 수 있는 카드 UI
  - 기본 상태: 첫 어절만 노출, 나머지는 블러 처리 또는 숨김
  - 탭하면 전체 문장 노출 (정답 확인)
- 절 순서를 랜덤으로 섞는 옵션(선택사항)
- 진행률 표시(예: "3/6 확인함")는 **페이지를 벗어나면 초기화되는 세션 한정 상태**로 충분 (DB 없음 MVP 범위이므로 영속 저장 불필요)

## 나중에 확장할 수 있는 것 (지금 범위 아님)

- 개인 진도 저장 → `localStorage`로 먼저 시도 가능 (로그인/DB 없이도 "이 기기에서 완료한 주차" 체크는 가능함). 여러 기기 동기화가 필요해지면 그때 Supabase 등 BaaS 도입 검토
- 조별 낭송 챌린지 타이머/기록 기능
- PWA 매니페스트 추가해서 "홈 화면에 추가" 지원

## 클로드 코드에서 시작할 때 붙여넣을 프롬프트 (예시)

```
이 폴더(data/, assets/, README.md)를 기반으로 Vite + React + TypeScript + Tailwind로
모바일 우선 정적 웹앱을 만들어줘. README.md의 "화면 구성 (MVP 범위)" 섹션대로
홈/주차상세/셀프테스트 3개 화면을 구현하고, data 폴더의 JSON과 assets의 SVG를 그대로 활용해줘.
배포는 Vercel 기준으로 바로 될 수 있게 설정해줘.
```
